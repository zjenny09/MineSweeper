## 2026-10-13 BGM 无声修复

- 已确认四首 BGM 均为 Godot 支持的 44.1 kHz、16-bit、立体声 PCM WAV，不是格式不兼容。
- 已确认文件不是静音：峰值约 -2.7～-2.9 dBFS，整体 RMS 约 -14.9～-16.2 dBFS，开头也有有效声音。
- 前三次修改主要提高音量、增加播放结束续播和看门狗，没有移除最不可靠的加载路径，因此没有真正消除问题。
- 旧实现通过 `AudioStreamWAV.load_from_file(ProjectSettings.globalize_path(...))` 绕过 Godot 的资源导入系统；编辑器与导出 PCK 的物理文件条件不同，这条路径不应继续用于正式 BGM。
- 现已将四首 BGM 改成脚本编译时 `preload` 的正式 Godot 音频资源，不再读取原始文件系统路径。
- BGM 不再在运行时篡改 WAV 循环属性；每首曲播放结束后由现有 `finished` 信号重新播放，避免错误循环区间造成静音。
- 播放前会显式停止旧曲、解除暂停、从 0 秒开始，并固定输出到 `Master` 总线。
- 保留每秒播放恢复看门狗，但只作为异常停止后的恢复手段。
