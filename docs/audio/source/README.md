# 休闲扫雷 · 音频使用说明

本文档说明本目录下全部背景音乐与音效的用途、播放时机和接入注意点，供策划、程序、其他关卡参考。

风格统一为：**剪纸风休闲游戏 + 任天堂田园配乐**。三套关卡（森林 / 海洋馆 / 天空）各有主题 BGM 和通关乐；菜单、失败音三个模式共用。

## 2. 背景音乐（BGM）

BGM 均按循环编写，**请在播放器或音频中间件里打开 Loop**。不要额外加淡入淡出，文件头尾已经接好（海洋、天空、菜单为环形缓冲；森林有淡入淡出，更适合进关一次播放，若要硬循环会有轻微呼吸感）。

### 2.1 菜单 `menu_select_bgm.wav`

- 场景：模式选择、主界面、关卡列表。
- 气质：C 大调、90 BPM，音乐盒 + 竖琴，不绑死某一种主题。
- 音量建议：比关卡 BGM 略低，避免盖过 UI 语音/按键。

### 2.2 森林 `forest_papercut_bgm.wav`

- 场景：森林剪纸关卡。
- 气质：G 大调、88 BPM；音乐盒主旋律，后半段偏亮的短笛；底层有虫鸣、蝉鸣底、树叶风。
- 循环：文件含淡入淡出，进关播放即可；若循环，接缝在收束回 G 大调处。

### 2.3 海洋馆 `ocean_papercut_bgm.wav`

- 场景：海洋剪纸关卡。
- 气质：D 大调、84 BPM；音乐盒 + 长笛短句；底层是**水流 + 海浪拍岸**，没有气泡（气泡只做点击音效）。
- 循环：可无缝 Loop。

### 2.4 天空 `sky_papercut_bgm.wav`

- 场景：天空剪纸关卡。
- 气质：C 大调、92 BPM；音乐盒 + 短笛；底层有风声、阵风、鸟叫。
- 循环：可无缝 Loop。

### BGM 切换建议

1. 进菜单：停关卡 BGM → 播 `menu_select_bgm.wav`（Loop）。
2. 进关：停菜单 → 按主题播对应关卡 BGM（Loop）。
3. 通关 / 失败：BGM 可降低 6–10 dB 或暂停，让庆祝/失败音效露出来；回到选关再恢复菜单 BGM。
4. 三首关卡曲不要叠着播。

## 3. 界面按键

| 文件 | 何时播放 | 设计意图 |
|------|----------|----------|
| `sfx_menu_select.wav` | 确认、进入、选中模式 | 往上跳的两声音乐盒（E→C） |
| `sfx_menu_back.wav` | 返回、关闭、取消 | 往回收的两声（G→C），比选择略低 |

注意：

- 一按就播，不要延迟。
- 连点时允许重叠，时长很短；若引擎支持，可用「同一音效只保留最新一次」避免叠成一团。
- 不要用在扫雷格子点击上（格子点击见下一节）。

## 4. 关卡内点击

### 4.1 海洋 · 点开格子 `sfx_clear_bubbles.wav`

- 一按就响的海浪泡沫气泡，约 0.28 秒。
- 适合：揭开安全格、翻开数字格。
- 不适合：通关庆祝（通关用 `sfx_win_ocean_SUCCESS.wav`）。

### 4.2 天空 · 点开格子 `sfx_sky_wind.wav`

- 约 2.15 秒，风绕着球转，转速较慢，尾音柔和拉长。
- **请与「球体被吹转」的动画同时开始**；动画时长建议对齐 2 秒左右，音效尾音可自然收。
- 连点很快时：建议截断上一次风声再播新的，或限制同时最多 1～2 个实例。

### 4.3 森林 · 点开格子

本目录暂无独立的森林点击音。可临时：

- 用 `sfx_menu_select.wav` 做轻点（偏 UI，不是最佳）；或
- 先静音点击，只保留 BGM；或
- 再单独做「落叶 / 花瓣」点击音后补进本表。

## 5. 通关庆祝（各模式一首）

三首结构接近（约 2.5 秒），都是短庆祝乐，**不要 Loop**。建议在最后一格揭开、判定胜利的同一帧播放。

| 文件 | 模式 | 意象 |
|------|------|------|
| `sfx_win_flower_SUCCESS.wav` | 森林 | 花骨朵 → 花瓣一层层打开 → 盛开 |
| `sfx_win_ocean_SUCCESS.wav` | 海洋馆 | 珍珠上浮 → 出水一溅 → 水光 |
| `sfx_win_sky_SUCCESS.wav` | 天空 | 云开 → 铃声上升 → 日出一闪 |

播放建议：

- 通关 UI / 花开（或对应特效）与音效同时起。
- 播完可以停在胜利界面，不必立刻切回菜单 BGM；玩家点「返回」再切。
- 不要和失败音叠播。

---

## 6. 失败（三模式共用）

**文件：** `sfx_fail.wav`（约 1.7 秒）

- 踩雷、关卡失败时播放。
- 意象：植物枯萎——干叶碎裂、茎气瘪下，带一点污浊低音。不是爆炸，也不是机器人音。
- 三个模式都用这一条，保持失败反馈一致。
- 不要 Loop。可与失败结算界面同时出现。

## 7. 推荐接入表（程序对照）

```
主菜单 / 选模式
  BGM  loop   menu_select_bgm.wav
  确认 one-shot sfx_menu_select.wav
  返回 one-shot sfx_menu_back.wav

森林关
  BGM  loop   forest_papercut_bgm.wav
  通关 one-shot sfx_win_flower_SUCCESS.wav
  失败 one-shot sfx_fail.wav

海洋关
  BGM  loop   ocean_papercut_bgm.wav
  点格 one-shot sfx_clear_bubbles.wav
  通关 one-shot sfx_win_ocean_SUCCESS.wav
  失败 one-shot sfx_fail.wav

天空关
  BGM  loop   sky_papercut_bgm.wav
  点格 one-shot sfx_sky_wind.wav   // 配吹球旋转动画
  通关 one-shot sfx_win_sky_SUCCESS.wav
  失败 one-shot sfx_fail.wav
```

音量起点（可再按真机调）：

- BGM：0.55～0.70
- 通关 / 失败：0.80～0.95
- 菜单按键、海洋点击：0.70～0.85
- 天空风声：0.60～0.75（较长，略压以免盖过 BGM）

## 9. 源文件（可选）

同目录下的 `.cs` 是生成器源码，用于重导出 WAV，游戏运行不必包含它们。

需要改旋律、时长或音色时，改对应 `.cs` 后重新生成并覆盖同名 wav 即可。

## 10. 还缺什么（已知）
