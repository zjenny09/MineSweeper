# 宇宙篇无尽星图首版进度

更新时间：2026-10-23

## 已确认方向

- 第四章节没有传统关卡编号、关卡列表或最终通关。
- 棋盘是一张持续向前生长的无尽宇宙星图；“区域”只作为生成器内部区块，不在玩家界面显示为关卡。
- 普通星核采用圆形节点，邻接只由可见发光连线决定；有线才相邻，没有线就不相邻。
- 普通节点以3～6邻接为主，少量大型恒星枢纽允许7～8邻接，最大不超过8。
- 不混用正方形格，避免玩家误认为角接触自动属于八邻接。

- 前七片梯度已固定；继续人工确认第3片虫洞、第5片辐射网、第6～7片高邻接枢纽的难度跃迁是否足够明显。

- 共用生态扫描能量、手柄与完整键盘操作尚未接入。
- 旧区域目前保留最近四片的缩略航迹；长期运行的归档表现等待体验后调整。
