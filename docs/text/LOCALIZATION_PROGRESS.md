# 中英双语接入进度

更新时间：2026-10-13

## 目标

- 游戏默认保持简体中文，并可在设置中切换 English。
- 语言选项写入现有存档，重新启动后继续使用上次选择。
- 主菜单、设置、章节地图、21关界面、机制对话、动态状态、暂停/结算界面和宇宙无尽模式均随语言切换。
- 使用 Godot 原生 TranslationServer 与中英文翻译资源，不为中英文复制场景或玩法代码。
- 程序和场景只保存稳定的 `TXT_####` 文案代号；中文与英文均由独立目录提供。
