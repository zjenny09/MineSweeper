## 机制约束

### 连续珊瑚礁带

- 珊瑚礁位于局部六边形之间，不占用整个格子，也不贯穿棋盘。
- 每次开局会在关卡约束范围内改变礁带分隔列、起点和长度；单段礁带始终连续，配置为两段的关卡则保留两段各自连续的礁带。
- 礁带相邻格会在局部缩小，为连续礁体留出空间；礁带不会覆盖格子内容。
- 被礁带隔开的共享边不构成六邻接，数字不统计另一侧的污染核心，零格展开也不跨越。
- 礁带两侧格子仍可正常翻开、插旗、双击展开与扫描；礁带上下端可以绕行。
- 污染核心按礁带所在列划分的区域面积成比例分配，避免几乎全部集中在一侧。
- 每个礁带上下端点的通道格固定为“一个核心 + 一个数字格”，不会出现0格；首次安全移雷也保留该端点约束。
- 当前直接使用用户最新生成的单体连续珊瑚枝完整素材；以单个纹理Line2D沿六边形真实边界顶点连续布线，整张素材一次拉伸，不再逐段裁切拼接；礁带位置与阻断规则保持不变。

### 洋流提示

- 每条洋流覆盖一组明确的六边形路径。
- 洋流标注该路径包含的污染核心总数。
- 洋流不移动污染核心、不自动翻格，也不穿过暗礁。
- 每局路径与数值在布雷完成后固定；重新开局时重新生成走向，每条路径至少包含1个污染核心，首次安全移雷后也保持非零。
- 洋流使用原始六邻接生成；撞到珊瑚礁时立即终止，只保留撞击前不少于两格的前半段，不在礁带另一侧继续生成第二段。
- 当前珊瑚礁已替换为用户提供的“珊瑚隔离带2”，保留其柔和粉珊瑚纹理并去除背景后继续沿单个Line2D布线。
- 每局至多选择一条洋流允许撞上礁带并截断；其他洋流生成时禁止穿过礁边，会绕过礁带继续流动。
- 每条有效洋流至少经过3格，并且必须包含一次方向变化；纯直线路径会被生成器重试并被最终校验拒绝。
- 洋流改为棋盘级连续平滑水流：使用柔和半透明双层曲线、、每条路径只保留一个方向标记，并将线位移到格子中心侧面以减少对数字的遮挡；终点总数改为与水流连接的纸片标记。
- 第11关保留一段已学过的短礁带，两条洋流改为绕过礁带端点的弯折路径，不再使用上下平行直线。

### 潮汐分区

- 尚未退潮的区域不可翻开、插旗或扫描，零格展开也不会提前进入锁定区。
- 普通数字会跨潮区边界统计相邻污染核心；下一区解锁后继承上一区边界数字形成的推理条件，已解锁区域之间恢复正常邻接。
- 当前区域安全格全部完成后解锁下一片区域。
- 开局一次性生成污染核心，解锁时不重新布雷。

- [x] 试玩修复：六边形数字不再在刷新格面时临时重算，而是由每局生成后固定的“实际共享边邻接图”统一提供；珊瑚墙阻断后的数字、零格展开、双击连锁和公开邻接均读取同一来源。潮汐推进改为每次从第一区开始重新核对各区全部安全格，第二区完成后可稳定推进并解锁第三区。
- [x] 第14关胜利按钮改为“返回地图”；按下后先显示已完成的海洋地图0.85秒，再播放翻页收合/展开动画进入天空篇地图。

## 人工体验重点

- 污染核心是否增加过快，尤其是第12～14关。
- 暗礁是否清楚表达“阻断邻接，但不阻断格子操作”。
- 洋流总数是否容易识别并参与推理。
- 潮汐区域的锁定、解锁顺序是否直观。
- `13×12`六边形在现有棋盘区域内是否仍足够清晰。
