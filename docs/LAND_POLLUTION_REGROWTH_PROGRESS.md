# 陆地污染根瘤再污染机制进度

> 更新时间：2026-10-29  
> 当前状态：功能已接入，等待用户人工测试与节奏确认。

## 已确定规则

- 第5～7关的污染根瘤启用局部再污染倒计时：第5关45秒、第6关40秒、第7关60秒。
- 玩家首次有效翻开安全格、进入游戏时，启动本关唯一的一组共享倒计时；不再要求先操作根瘤邻格。后续普通翻格、标记和探测不会续时。
- 在时限内净化一组根瘤后，只刷新共享倒计时并继续处理剩余根瘤，不显示单组净化提示；全部完成后停止倒计时并显示“所有污染根瘤已全部净化”。
- 超时时，对仍未净化且已有操作进度的根瘤组，覆盖组内根瘤周围两圈可操作棋盘格作为局部再污染范围：
  - 已翻开的安全格重新盖回。
  - 范围内标记和扫描确认状态撤销。
  - 范围内污染核心保持相同数量并重新随机位置。
  - 范围外的翻开状态、标记、确认状态和污染核心位置完全不变。
  - 全盘总污染核心数量保持不变。
  - 重新计算所有邻接数字，因此范围边缘仍然翻开的数字格会同步变化。
- 若倒计时结束时该范围内已经没有翻开、标记或确认状态，则不改变棋盘。
- 开场引导时尚未翻格，不启动倒计时；暂停和棋盘交互锁定期间不推进倒计时。
- 超时后自动开始下一轮共享倒计时；即使范围内没有需要重置的进度，倒计时也继续循环，全部根瘤净化后才停止。
