# 中英双语接入进度

更新时间：2026-10-13

## 目标

- 游戏默认保持简体中文，并可在设置中切换 English。
- 语言选项写入现有存档，重新启动后继续使用上次选择。
- 主菜单、设置、章节地图、21关界面、机制对话、动态状态、暂停/结算界面和宇宙无尽模式均随语言切换。
- 使用 Godot 原生 TranslationServer 与英文翻译资源，不为中英文复制场景或玩法代码。
- 中文继续作为源文案；英文界面采用当前手写字体中的拉丁字符。

## 实施记录

- 使用 `res://localization/green_sweeper.en.po` 作为英文翻译目录，并在 `project.godot` 中登记；简体中文继续直接使用现有源文案。
- 设置页新增 `语言 / Language` 选项，支持“简体中文”和“English”。选择后立即调用 `TranslationServer.set_locale()`，同时刷新章节地图、动态关卡信息和当前运行中的玩法界面。
- 语言以 `zh_CN` / `en` 写入现有 `settings` 存档；旧schema 6存档没有该字段时默认简体中文，不需要清档。
- 动态计数、关卡名、状态提示、扫描提示、漂流水雷倒计时、潮区反馈、球面增益、雷眼、星网邻接和远征结算均使用可格式化翻译模板；机制对话保留一份中文源数据，由共用纸片框实时翻译。
- 英文目录覆盖当前脚本与场景中的全部中文界面源字符串；不包含测试断言文本和开发文档。
- 2026-10-12人工反馈：首轮英文直接沿用中文手写字体与字号，英文过宽且观感不佳。现加入采用OFL授权的 `Patrick Hand` 英文字体；切换English时统一缩小界面文字，切回中文时恢复每个控件原有字体与字号。机制纸片框在英文模式下同步加宽加高，正文与提示启用自动换行；地图圆形节点改显示关卡编号，完整英文关卡名保留在下方信息栏和悬停提示中。
- 同轮反馈指出只能听见音效。背景音乐整体音量已提高，并以播放器结束信号保证曲目播完后继续循环；宇宙篇不再主动停止音乐，改为持续播放较轻的天空/宇宙背景曲。
- 2026-10-12后续人工反馈：陆地/海洋左侧便签的英文规则仍然过长。已将英文目标与规则压缩为短句，删除中文原文中不必逐字保留的重复解释；漂流组、珊瑚墙、污染节点、潮区和键盘说明均改为便签可读的简短表达。
- 背景音乐第二轮加固：BGM改为直接读取原始WAV，避开长音频导入流可能失效的问题；增加每秒播放看门狗，播放器意外停止时自动恢复。音效仍走原来的独立播放器，不与BGM抢占声道。

不运行自动玩法测试，不自行判定翻译或视觉效果通过。
