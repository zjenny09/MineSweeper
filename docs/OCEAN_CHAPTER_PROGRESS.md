# 海洋篇基础关卡进度

> 当前目标：先验证六边形扫雷是否好玩；页面与正式海洋美术暂缓。

## 已确定路线

1. 潮池初醒：5 × 5 六边形格，5 个污染核心
2. 海草摇篮：6 × 6 六边形格，7 个污染核心
3. 珊瑚花园：7 × 7 六边形格，10 个污染核心
4. 海藻森林：8 × 8 六边形格，14 个污染核心
5. 深海鲸落：10 × 9 六边形格，22 个污染核心

## 当前基础实现

- [x] 海洋篇保留 5 关结构，对应总关卡编号 6–10。
- [x] 使用尖顶朝上的错行六边形格。
- [x] 每格最多有 6 个相邻格。
- [x] 六边形点击区域与实际轮廓一致。
- [x] 暂用程序绘制的蓝绿色六边形样式。
- [x] 陆地选关地图和五关存档结构保持不变。
- [x] 海洋篇首击会生成安全的有限展开区，不会再一点击就直接通关。
- [x] 可通过 `--level=6` 直接启动海洋第一关进行手感验证。

## 后续暂不处理

- 海洋篇入口和选关页面。
- 海洋桌面、棋盘框、守护物、失败状态和贴纸美术。
- 海流等海洋专属附加机制。
