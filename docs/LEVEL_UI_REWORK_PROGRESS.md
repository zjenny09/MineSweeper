## 用户要求

- 不进行中途迭代、运行或测试；全部完成后只打开一次游戏，由用户手动验收。
- 胜利后的“下一关”按钮文字保持单行。
- 第 1–5 关按各关素材更换装饰贴纸，位置和角度有差异。

## 关键修改位置

- `scripts/main.gd`：单行胜利按钮、按关中央装饰、按关贴纸布局。
- `scripts/art_catalog.gd`：新装饰、贴纸和选关页资源常量。
- `scenes/shell.tscn`：地图式选关页面静态布局。
- `scripts/shell.gd`：地图节点生成、选择状态、底栏信息和返回逻辑。
- `assets/art/land_levels/`：第2–5关透明装饰与贴纸运行资产。
- `assets/art/level_select/`：选关页背景、地图、底栏和按钮运行资产。
