# 统一机器人、海洋生态素材与扫描机制实施记录

更新时间：2026-09-03

## 目标

- 第6–10关在底部中心显示各自的健康生态素材，失败时切换同关“枯萎”素材，胜利时使用黄色小光点波动。
- 陆地机器人扩展至全部10关；胜利时进行更大幅度的跳舞和向上挥臂，失败时统一倒地、漏电并独立挥舞双臂。
- 第1–10关统一点击机器人或按 `C` 启动扫描，并共享相同的目标/结果动画。
- 扫描改为可重复充能：12次有效操作充满，电量与首关赠送状态跨关、重开、选关和应用重启保存。
- 本文件作为上下文超长、执行超时或中断后的唯一恢复入口。

## 固定产品规则

### 扫描充能

- 容量固定为 `12`。
- 某个存档第一次进入第1关时赠送一次 `12/12`；此后回到第1关、重开或重新启动应用都不会再次赠送。
- 满12格可扫描；一次有效扫描原子消费12格，然后立即开始下一轮充能。同一局可以重新充满并再次使用。
- 每个棋盘仍需先完成第一次普通翻开，才能启动扫描，避免破坏首点布雷和首点保护。
- 以下每次增加1格：
  - 手动翻开且至少新增一个安全格；
  - 有效快速展开且至少新增一个安全格；
  - 某隐藏格在当前棋盘第一次从未标记变为插旗。
- 以下不充能：无效点击、重复展开、取消旗、同一格重新插旗、踩雷、扫描产生的翻开。
- 获胜的最后一次有效手动翻开/快速展开仍增加1格；失败踩雷不增加。
- 电量跨1–10关、重开、选关页面、返回首页和应用重启保存。
- 第1–10关统一使用条件安全开局：同一关连续2次首点踩雷后，仅该关下一局启用一次首点安全；同一关连续3次在5步内失败后，仅该关下一局启用一次安全区域开局。
- “下一局”只指重开/重新生成同一关，不指进入下一关；失败计数和辅助资格不得跨关继承。
- 机器人点击与键盘 `C` 必须进入完全相同的状态机。

### 海洋生态素材

- 保留每个主体的沙地底座和内部结构阴影。
- 删除灰蓝摄影背景、右下水印和沙地底座之外的落地投影。
- 正常/枯萎对必须使用相同画布、底线和视觉中心，切换时不得跳位。
- 第10关保留完整鲸落微缩生态构图，等比缩放，不横向压扁。
- 不覆盖 `docs/ui_history` 中的源图。
- 自动抠图只作为初稿；未经四色背景和游戏实画面检查，不标记为正式通过。

- 当前第5关胜利不会直接推进第6关。
- 当前存档仅持久化陆地进度、最佳时间和设置，没有扫描电量。
