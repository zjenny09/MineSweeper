# 勋章本槽位布局规格

> 基准素材：`docs/art/ver2bygpt/勋章本.png`  
> 源图尺寸：`1448 × 1086`  
> 运行画布：`1280 × 720`

## 分析方法

- 对勋章本源图执行灰度 Canny 边缘提取。
- 以左上第一个完整盾框（含下方绶带）的 `300 × 370` 区域作为模板。
- 在全图进行归一化相关模板匹配并执行非极大值抑制，得到七个重复槽位的外框位置。
- 槽位中心和外框记录在源图坐标中，运行时只通过统一映射换算，不再逐张凭肉眼单独摆放。

## Godot 运行坐标

`BookArt` 在未缩放的 `BookVisual` 中使用矩形：

```text
Rect2(160, 0, 960, 720)
```

因为源图与目标矩形均为 `4:3`，X/Y 使用相同换算比例：

```text
960 / 1448 = 720 / 1086 ≈ 0.662983
```

七个 `TextureRect` 使用以下整数化矩形：

| 关卡 | `Badge#` 矩形 | 控件中心 |
|---|---:|---:|
| 1 | `(222, 89, 200, 246)` | `(322, 212)` |
| 2 | `(413, 89, 200, 246)` | `(513, 212)` |
| 3 | `(655, 89, 200, 246)` | `(755, 212)` |
| 4 | `(847, 89, 200, 246)` | `(947, 212)` |
| 5 | `(220, 328, 200, 246)` | `(320, 451)` |
| 6 | `(413, 328, 200, 246)` | `(513, 451)` |
| 7 | `(655, 328, 200, 246)` | `(755, 451)` |

勋章本整体围绕 `(640, 360)` 以 `0.82` 缩放；勋章按槽位原始 `100%` 显示，最终屏幕矩形约为 `164 × 201.7`。最终中心保持不变：

```text
1 (379.2, 238.6)   2 (535.9, 238.6)
3 (734.3, 238.6)   4 (891.7, 238.6)
5 (377.6, 434.6)   6 (535.9, 434.6)
7 (734.3, 434.6)
```

勋章素材在处理阶段按原有 Alpha 边界裁切并保留安全边距。陆地、海洋、天空的中英文勋章共用 `STRETCH_KEEP_ASPECT_COVERED`，以槽位中心为轴按 `100%` 显示，单枚未缩放书本坐标下的显示矩形为 `200 × 246`。2026-10-28 根据用户反馈将 `94%` 恢复为 `100%`，以覆盖下方空槽，不再使用 `106%` 放大覆盖。新获得勋章的入册缩放继续使用 `TRANS_CUBIC / EASE_OUT`，不越过最终大小；书本整体开启动画保持不变。已实跑三章页面与入册动画，确认最终缩放为 `100%`，动画不超出该尺寸。

## 翻页按钮锚点

右页翻页按钮在未缩放 `BookVisual` 中使用：

```text
Rect2(914, 438, 84, 84)
```

应用 `0.82` 书本缩放后，屏幕矩形约为：

```text
Rect2(864.7, 424.0, 68.9, 68.9)
```

该位置对应右侧书页的下部空白内容区，而不是整本外框的右下角。

## 编辑器微调

- 打开 `scenes/badge_book.tscn` 的 2D 页面；书本、七枚陆地中文勋章及翻页按钮已绑定预览贴图，编辑时无需运行游戏。
- 在 `BookVisual` 下选择 `Badge1`～`Badge7`，拖动调整位置，或在检查器的 `Layout > Transform` 中修改 `Position`、`Size`。
- 运行时将勋章 `Scale` 设回 `100%`，因此尺寸调整应修改 `Size`，不要依赖 `Scale`；同一套位置和尺寸由三章中英文勋章共用。
- 预览贴图不改变完成进度；游戏内仍按实际完成记录和语言切换贴图。手动调整后按 `Ctrl+S` 保存，再重新导出 exe。
