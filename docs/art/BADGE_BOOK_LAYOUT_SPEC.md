# 勋章本槽位布局规格

> 基准素材：`docs/art/ver2bygpt/勋章本.png`  
> 源图尺寸：`1448 × 1086`  
> 运行画布：`1280 × 720`

## 分析方法

- 对勋章本源图执行灰度 Canny 边缘提取。
- 以左上第一个完整盾框（含下方绶带）的 `300 × 370` 区域作为模板。
- 在全图进行归一化相关模板匹配并执行非极大值抑制，得到七个重复槽位的外框位置。
- 槽位中心和外框记录在源图坐标中，运行时只通过统一映射换算，不再逐张凭肉眼单独摆放。

## Godot 运行坐标

`BookArt` 在未缩放的 `BookVisual` 中使用矩形：

```text
Rect2(160, 0, 960, 720)
```

因为源图与目标矩形均为 `4:3`，X/Y 使用相同换算比例：

```text
960 / 1448 = 720 / 1086 ≈ 0.662983
```

七个 `TextureRect` 使用以下整数化矩形：

| 关卡 | `Badge#` 矩形 | 控件中心 |
|---|---:|---:|
| 1 | `(222, 89, 200, 246)` | `(322, 212)` |
| 2 | `(413, 89, 200, 246)` | `(513, 212)` |
| 3 | `(655, 89, 200, 246)` | `(755, 212)` |
| 4 | `(847, 89, 200, 246)` | `(947, 212)` |
| 5 | `(220, 328, 200, 246)` | `(320, 451)` |
| 6 | `(413, 328, 200, 246)` | `(513, 451)` |
| 7 | `(655, 328, 200, 246)` | `(755, 451)` |

勋章本整体围绕 `(640, 360)` 以 `0.82` 缩放，因此最终屏幕槽位约为 `164 × 201.7`；最终中心约为：

```text
1 (379.2, 238.6)   2 (535.9, 238.6)
3 (734.3, 238.6)   4 (891.7, 238.6)
5 (377.6, 434.6)   6 (535.9, 434.6)
7 (734.3, 434.6)
```

勋章素材在处理阶段按原有 Alpha 边界裁切并保留安全边距。实机截图显示，各勋章源图裁切后的宽高比约为 `0.817–0.853`，而槽位宽高比约为 `0.811`；若继续等比居中会产生上下或左右的可见偏差。因此七个运行槽统一使用 `STRETCH_SCALE` 精确填满上述矩形，以槽位外框对齐优先。

## 翻页按钮锚点

右页翻页按钮在未缩放 `BookVisual` 中使用：

```text
Rect2(914, 438, 84, 84)
```

应用 `0.82` 书本缩放后，屏幕矩形约为：

```text
Rect2(864.7, 424.0, 68.9, 68.9)
```

该位置对应右侧书页的下部空白内容区，而不是整本外框的右下角。
