- `OceanDeskBackground`
- `OceanStageArt`
- `OceanLeftInfo`
- `OceanBoardArea`
- `OceanRightInfo`
- `OceanQuickActions`
- `OceanTopHud`
- `OceanRobot`
- `OceanEcology`
