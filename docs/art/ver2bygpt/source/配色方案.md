
## 3. 生产规格

### 3.1 游戏基准

- 逻辑画布：1280×720；
- 全屏背景母版：2560×1440 或更高的 16:9；
- 桌面章节背景可继续使用：2848×1600；
- 独立角色、生态主体：1024×1024 RGBA；
- 大型生态主体：1536×1024 RGBA；
- 小图标、标记、棋盘格：512×512 RGBA；
- 对话框：1200×436 RGBA，最终缩至 600×218；
- 按钮底板：先生成 1024×256 或 512×512，再裁切和制作 9-slice；
- 所有状态组必须使用完全相同的画布、中心、基线、缩放和透明边界。

### 3.2 UI 安全要求

- 独立素材：真正透明背景；
- 不生成文字、字母、数字、Logo、签名、水印；
- 不生成棋盘格透明背景图案；
- 主体四周至少留 8% 安全边距；
- 小图标缩至 48–96px 后仍须一眼可辨；
- 不依靠极细纹理和微小零件传达状态；
- 外部投影默认关闭，由 Godot 统一绘制；
- 允许纸片内部有轻微层间遮蔽，但不能形成第二个落地影；
- 同组 normal / hover / pressed / focus 状态不得改变轮廓和占位。

### 3.3 固定光照

除全屏背景外，所有独立素材统一采用：

- 柔和工作室散射光；
- 主光从左上方约 35° 入射；
- 纸层内部只产生短而柔和的右下遮蔽；
- 无强烈高光、无镜面反射、无电影级景深；
- 正交或近似正交视角，避免夸张透视。
