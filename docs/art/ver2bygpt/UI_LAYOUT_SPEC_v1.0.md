# Minesweeper — UI 布局与尺寸规范 v1.0

- 状态：**布局基准已确认；概念图造型未确认**
- 画布：**1280 × 720 Godot 逻辑像素**（16:9）
- 适用章节：**陆地、海洋、天空、宇宙**。四章继承同一布局规则；只允许生态主题、配色、纸艺纹理和关卡格子图案变化。
- 权责：由项目主导者确认视觉方案；本规范不意味着批准任何一张布局示意图中的装饰造型。

## 1. 已确认的硬约束

1. **无顶部信息栏**：所有游戏信息集中在左右信息区。
2. **上方为一体化三联纸板造型**：中央棋盘框与左右信息栏呈现为一件视觉整体，而不是三个彼此独立的盒子；工程上可以拆图、分层实现。
3. **中央棋盘为视觉中心**；左右信息区严格镜像对称、正视、无倾斜扭曲。
4. **棋盘框不包含棋盘格**：中央是透明方形开口，格子由 Godot 按关卡动态绘制。
5. 棋盘最大 **13 × 13 = 169 格**。
6. 下方是独立的角色与生态动画舞台，包含机器人主角、守护者及储能、提示、成功、失败演出；**所有角色及动画不得进入棋盘区域**。
7. 左右信息区较原方案收窄，保留背景与生态视觉展示空间。

## 3. 13×13 格子适配

- `442 / 13 = 34`，满棋盘时单格恰为 **34 × 34 逻辑像素**。
- 小棋盘允许居中排布或统一缩放，但不改变中央框和信息栏的占位。
- 纸格、数字、旗帜和危险标记必须按**实际显示尺寸**校验：先在 34px 下审查清晰度，再制作 2× 或 4× 源图。
- 棋盘贴图、格子和状态特效均由 Godot 分层处理；不要烘焙进棋盘框。

## 4. 视觉风格继承（四章共用）

**固定语言**：温暖童话生态世界、手工再生纸板、分层剪纸、桌面微缩舞台、手写界面。近正视角；有限纸厚与纤维；光源左上约 35°；独立素材不包含外部落地影。

**章节可变**：陆地、海洋、天空、宇宙的色板、植物/生物/天体装饰、棋盘格纸面与局部角色舞台布景。

**章节不可变**：1280×720 画布、操作区/舞台分界、中央棋盘开口与最大 13×13 布局、左右镜像对称、无顶部信息栏、动画不进入棋盘、可读性要求。

配色以项目当前已确认的《配色修正记录》和色卡为准；本文件**不修改配色，也不批准新造型**。

## 5. 不纳入本版批准范围

- 上方横向大边框的具体外形、厚度、连接方式；
- 植物、树叶、标牌、栅栏等装饰的具体数量与位置；
- 机器人、守护者的形象与舞台贴纸造型；
- 任何尺寸图中的手写文字样式与配色细节。

这些内容必须另行出**真实 1280×720 比例**的概念图，由项目主导者逐项确认。

## 6. 生产与验收

1. 先按上述逻辑尺寸制作**无装饰线框布局**，按 1280×720 实际比例检查。
2. 在 34px 棋盘格下测试数字、旗帜与状态辨识度。
3. 角色动画先提供最大动作包围盒，确保不越入棋盘开口；必要时调整舞台内部站位，而非自行扩大上方区域。
4. 上方允许视觉一体化，但实际实现建议独立的透明棋盘开口、左右内容容器和分层纸板图，便于 Godot 维护。
5. 四章先共享这一布局，出现无法适配的章内特殊需求时，应提出变更申请并记录版本，不得静默修改。
