# 美术方向决策记录

## 2026-10-13 — 已确认

- 创作主导：由游戏作者主导，AI 仅协助提案、概念图生成和检查。
- 核心风格：温暖童话生态世界 + 手工再生纸板 + 分层剪纸 + 桌面微缩舞台 + 手写界面。
- 四个章节：陆地、海洋、天空、宇宙。
- 标准色彩：以 `source/配色方案.md` 为准；作者当前满意配色，不随意替换 HEX。
- 纸张肌理、柔和光照可产生表现色，但不能取代基础色板。
- 首轮概念图：`concepts/four_worlds_concept_v01.png`，仅用于比较世界观及视觉搭配，不是可直接用于游戏的分层素材。
- 已上传的六张原始参考图片位于 `references/`。
- 生产规格与 UI 安全约束均应以 `source/配色方案.md` 为准，特别是不在独立素材内生成文字、水印和外部落地影。

## 更新规则

1. 每次更新新增一个日期标题，不直接覆盖旧的审美结论。
2. 每次生成图都存 PNG 和对应说明文档，并记下关卡、版本、所依据的色板与评审状态。
3. 未经作者确认的提议统一标注“待确认”，不能当成已确定的规范。
