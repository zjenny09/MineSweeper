## 原始快照说明

这是当前回合的本地备份：原始配色规范、素材目录、六张参考图、四关卡概念拼图与已确认的设计决策。

建议将压缩包解压到 `D:\o!mygame\minesweeper\docs\art\` 的一个版本文件夹中，避免覆盖已有同名文件。

文件说明：
- `source/`：用户提供的标准文档，未改写。
- `references/`：用户提供的六张参考图，未改写。
- `concepts/`：首轮生成的四章节综合概念图。
- `ART_DECISIONS.md`：当下设计共识和待定事项。

注意：概念图中的文字、数字、棋盘只是视觉概念，不符合独立资产禁止烘焙文本和水印的规范，不应用作最终游戏素材。
