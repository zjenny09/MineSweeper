# 陆地关卡新版界面接入进度

> 状态：进行中  
> 目标：将 `docs/art/ver2bygpt` 的候选素材接入真实 Godot 陆地关卡，由用户在游戏中人工确认视觉效果。

## 不变约束

- 运行素材必须复制到 `assets/art/`，不直接引用 `docs/`。
- 生成按钮图片保持无文字；中文/英文文字由 Godot `Label` 与 `TXT_####` 翻译键渲染。
- 悬停、键盘焦点、扫描目标和扫描结果继续由 `cell.gd` 程序绘制，不新增或混用旧风格状态图。
- v1.0/v1.1 中互相冲突的尺寸不逐项硬套；保持三联舞台整体比例，在 1280×720 画布中优先保证棋盘为正方形、底部角色区不遮挡操作区。
- 不用自动截图或自动玩法测试判断效果，最终视觉由用户在真实游戏窗口中确认。
